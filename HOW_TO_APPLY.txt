SimpleSavant v3 — code-only fix (IMPORTANT)

The ZIP you uploaded did not contain the advanced-stat raw values you downloaded with enrich_raw_stats.py.
This update deliberately excludes ALL player data and team logos so your enriched local files stay intact.

How to install on Windows:
1. Stop the Python web server (Ctrl+C).
2. Open the existing SimpleSavant folder (where you already ran enrich_raw_stats.py).
3. Extract THIS patch ZIP into that folder and choose Replace existing files.
   It overwrites only index.html, batting.html, pitching.html, css/, js/, and templates/.
   Do NOT delete or replace your existing data/ or assets/ folders.
4. Start the server: py -3.11 -m http.server 8000
5. Refresh browser with Ctrl+F5.

Expected results:
- Clicking Overall Hitting or Overall Pitching lists only the four category weights.
- Clicking an individual category shows real stat values, e.g. ERA 2.21, exit velo 95.3 mph, barrel rate 24.8%, when in your data.
- Bars still use internal percentiles; no numeric percentile labels appear next to bars or in raw-stat rows.
- Team logo appears to right of name; square logo appears in search result.
- Missing values display N/A.

If a profile shows the amber warning 'This copy of the player data does not yet include actual advanced-stat values', verify the data/players/*.json files in THAT folder include fields such as batting_raw or pitching_raw; run enrich_raw_stats.py there if not.
